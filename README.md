## 💡 Sobre o Projeto

O **VozPública** é uma ferramenta voltada para a realização de pesquisas eleitorais e de opinião de forma ágil e estruturada em campo. O aplicativo permite que o usuário registre dados de entrevistados, capte a localização e o horário de forma automática, e conduza formulários dinâmicos cobrindo intenções de voto (pesquisas espontâneas e estimuladas) e os principais problemas sociais apontados pela população.

---

## 📱 Funcionalidades Principais

* **🔒 Tela de Acesso / Login:** Controle de entrada para entrevistadores e administradores.
* **📋 Cadastro de Entrevistados:** Coleta de nome e contato, registrando automaticamente metadados como data, hora e geolocalização.
* **🗳️ Pesquisa Espontânea e Estimulada:** Módulo interativo para registro de votos para o cargo presidencial com as informações de cada candidato.
* **📊 Diagnóstico de Problemas:** Seleção rápida das principais demandas da sociedade (Saúde, Educação, Segurança, Economia, etc.).
* **📈 Módulo de Resultados:** Visualização e gerenciamento prático dos dados resultantes da coleta direta no app.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído nativamente para o ecossistema Android, utilizando as seguintes tecnologias e conceitos:

* **[Android Studio](https://developer.android.com/studio):** Ambiente de desenvolvimento integrado oficial para plataformas Android.
* **[Kotlin](https://kotlinlang.org/):** Linguagem principal para toda a lógica de negócio e manipulação de fluxos das telas (`Activities`/`Fragments`).
* **[Android SDK](https://developer.android.com/):** APIs nativas do Android para construção de interfaces e gerenciamento de ciclo de vida.
* **XML:** Estilização de layouts de interface de usuário (`UI`) e centralização de textos estruturados (`strings.xml`).
